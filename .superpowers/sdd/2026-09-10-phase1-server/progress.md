Every push authenticated as that user, which has no access to bnfarrell/message_app, and GitHub returns 404 (not 403) in that case — which is why it was indistinguishable from "repo does not exist" and why my anonymous curl probes could never resolve it. The repo existed the whole time and is PRIVATE. Cleared with `printf "protocol=https\nhost=github.com\n\n" | git credential reject`; the user then signed in as bnfarrell and the push succeeded.
Lesson worth keeping: when a GitHub remote 404s, check the AUTHENTICATED IDENTITY (`git credential fill`) before concluding the repository is missing. A stale credential for a different account presents identically to a nonexistent repo.
